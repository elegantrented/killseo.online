# killseo.online

Plain HTML site. Hosted on Cloudflare, which rebuilds and publishes it automatically every time this repo's `main` branch changes. Nothing to run locally.

## Add or change links
Edit **`links.txt`** on GitHub (pencil icon), one link per line, then commit:

```
https://example.com
https://example.com | Text people click on
```

All links are normal follow links. The list on the page is rebuilt from this file on every publish, so don't edit the list inside `index.html` directly.

## Change anything else
Edit **`index.html`** on GitHub and commit. Live in about a minute.
